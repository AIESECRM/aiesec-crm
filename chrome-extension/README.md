# AIESEC CRM Chrome Eklentisi (Google Maps Web Clipper)

AIESEC B2B ekip üyelerinin Google Haritalar üzerinde gezerken potansiyel işletmeleri anında algılamasını, CRM veritabanı ile çakışma kontrolü yapmasını ve tek tıkla kendi şubelerine eklemesini sağlar.

## Kurulum Adımları (5 Saniye)

1. Google Chrome tarayıcınızı açın ve adres çubuğuna şunu yazın: `chrome://extensions`
2. Sağ üst köşedeki **"Geliştirici modu" (Developer mode)** anahtarını açın.
3. Sol üstteki **"Paketlenmemiş öğe yükle" (Load unpacked)** butonuna tıklayın.
4. Bilgisayarınızdaki bu `chrome-extension` klasörünü seçin.

Eklenti tarayıcınıza eklendi!

## Nasıl Kullanılır?

1. Google Haritalar (`maps.google.com`) üzerinde herhangi bir arama yapın (Örn: *Aydın Dil Okulları*).
2. Bir işletmenin detayına tıkladığınızda işletme başlığının hemen altında **AIESEC CRM ⚡ Şubeme Ekle** butonu belirecektir.
3. Veya sağ üstteki eklenti ikonumuza tıklayarak **⚡ Aktif Harita Sayfasını Tara** diyebilir, CRM çakışma durumunu görebilirsiniz!
